| 1 | 4 | Working example: significant financing component | Internally inconsistent. | 2 | 4 | Exam technique: example format (performance bonus) | A single R100,000 bonus with an 80% chance is a two-outcome case. This part's own Method 2 example (identical facts) and its pitfall table say to use the most likely amount, R100,000 (IFRS 15.53(b)). The model format instead uses expected value (R80,000, which is not a possible outcome), then an unexplained R30,000 'constraint' to reach R50,000. Students copying this format lose the method marks. | not on web pages |  |

The constraint's actual two elements are the likelihood and the magnitude of a significant reversal of cumulative revenue (15.56-57). It also contradicts the table directly below and the worked example, which still includes R50,000 of a bonus exposed to both factors. The web page (part 3) states the constraint correctly. | not on web pages |  |
